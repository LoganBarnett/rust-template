* Read =template/llms.org= first

The primary set of conventions lives in [[file:template/llms.org][=template/llms.org=]] — read it
first.  Those are the conventions emitted into spawned projects, and
the rust-template repo itself (the foundation crate, the
foundation-derive proc-macro, the template generation scripts) holds
itself to the same standards.

The whole point of rust-template is to /capture learnings as
code and config/.  Exempting this repo from its own conventions would
defeat that — so when in doubt, the template's rule applies here too.
