#+title:     Changelog
#+language:  en

* Upcoming
** Added
- =template/nix/modules/common.nix= as the cross-platform seam for the spawned
  project's NixOS and nix-darwin modules.  The file is intentionally near-empty
  at spawn time; it exists so the project author has a single well-known
  location for declarations that should apply on both platforms, with no
  restructuring required when the first shared bit lands.
** Changed
* v0.6.0
** Changed
- Backfilled the v0.4.0 and v0.5.0 sections, which the release workflow had
  emitted empty because their pushes carried no Upcoming entries.
- =template/flake.nix= and =compliance-check.sh= now invoke =jq= with
  =--raw-output= rather than =-r=, matching the long-form convention in
  =template/llms.org=.  Newly spawned projects inherit the long-form invocation;
  existing spawns can pick it up via a forward-port.
- =template/nix/modules/nixos-server.nix= and =darwin-server.nix= now return ={
  imports = [ ./common.nix (foundation.lib.mkXService { … }) ]; }= rather than
  the bare =mkXService= call.  Future platform-specific declarations
  (=systemd.tmpfiles=, =launchd.daemons=, etc.) can be added inline without
  restructuring the file, and the module-merge system handles the seam.
* v0.5.0
** Changed
- Bumped template's top-level =changelog-roller= input past the SSH-to-HTTPS
  orgize fix so freshly-spawned projects no longer re-evaluate a build that
  fails on clean CI runners without a github SSH key.
* v0.4.0
** Fixed
- =test-formatters.sh= now dumps the spawn-clean treefmt log on failure so a CI
  Formatter-coverage red surfaces the actual error instead of a path to a
  per-run tmp file no one outside the runner can read.
* v0.3.0
** Added
- =--all-features= on the reusable CI workflow's =cargo test= and =cargo clippy=
  steps so feature-gated code paths actually get exercised rather than passing
  by not being compiled.
- =required-features= declarations on the foundation crate's MergeConfig
  integration tests so they compile under the =cli= feature and are skipped
  without it.
** Changed
- Bumped org-fmt to pick up the list-marker recognizer fix (it no longer
  mistakes any =word.= at line start for an ordered-list marker) and the
  idempotent =--in-place= mode (no rewrite when content is unchanged), which
  together unblock the formatter-coverage CI job.
** Fixed
- Combinator-preference clippy violations across foundation's auth and server
  modules and the MergeConfig derive macro, surfaced once the org-fmt SSH
  dependency no longer masked the clippy step in CI.
* v0.2.0
** Added
- Multi-crate workspace publishing via =cargo publish --workspace= in the
  reusable publish workflow.
- =[workspace.dependencies]= pattern with lockstep version bumping for
  inter-crate path deps.
- =trusted-publish-setup.sh= for crates.io trusted-publishing configuration,
  with a =pass= fallback for the API token.
